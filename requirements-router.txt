# Pinned for a typical OpenWrt router deployment (musl libc + aarch64 +
# Python 3.9, e.g. a GL.iNet travel router). Do NOT let pip pick "latest"
# here if your router is in a similar situation: dbus-fast versions
# outside this range either require Python >=3.10 or lack a prebuilt wheel
# for this platform, which forces a from-source Cython build - this device
# has no compiler, and attempting that build already caused two real
# disruptions to the router's live network on the previous (A1300) unit.
#
# Verified 2026-09-17 directly against PyPI's published wheels for this
# exact combination (cp39 + musllinux_1_2_aarch64) - see the two "has
# musllinux_aarch64 cp39 wheel: True" checks. 2.22.1-2.26.0 and 2.28.0-2.29.0
# all qualify; 2.27.0 appears to be a one-off gap in that specific release's
# published wheels, not a trend - avoid it.
#
# bleak itself also requires Python >=3.10 from version 1.1.2 onward - the
# last version supporting Python 3.9 is 1.1.1, which needs dbus-fast>=1.83.0
# (no upper bound), so it's compatible with the pin above. Confirmed this
# the hard way: the Mac's own requirements.txt pins bleak>=3.0.2, which does
# NOT work here - the two platforms need genuinely different bleak versions.
dbus-fast==2.29.0
bleak==1.1.1
