Restart BLE receiver

If battery or charger data goes missing or gets stuck and doesn't come back on its own, use this to restart the ESP32 - it briefly drops the connection to both devices and reconnects fresh, same as unplugging and replugging it. Takes about 15-20 seconds.

Device connections

The BLE MAC addresses the ESP32 bridge connects to for the battery and charger - change these to point this dashboard at different (or someone else's) devices without reflashing firmware. Format: AA:BB:CC:DD:EE:FF. Each applies independently, and reconnects the ESP32 to that device - double-check before applying.

Scan for devices

Finds nearby BLE devices to help set up a battery/charger for the first time - useful if you don't already know the MAC address. This disconnects the ESP32 from whatever it's currently connected to for a few seconds while it scans, so it's meant for initial setup, not something to run routinely.
